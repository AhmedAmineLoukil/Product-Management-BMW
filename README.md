# BMW Product Signal Desk

A small, interactive prototype for the BMW Product Management Challenge.

It demonstrates the path from customer evidence to a proposed requirement, a transparent priority, a product-manager decision, and an audit trail.

## Run it

Open `index.html` in a web browser. It uses plain HTML, CSS, and JavaScript, so there is nothing to install.

## Important: sample content

The feedback snippets and scores shown in this prototype are fictional examples. They are not BMW customer data and must not be presented as real findings. Replace them only with approved evidence from the challenge Drive, and keep the original input files out of this repository.

## What the prototype demonstrates

- Select a vehicle derivative and market.
- Review candidate customer requirements and their linked evidence.
- See an explainable example score.
- Approve, reject, or edit a requirement as the product manager.
- Review a local audit history of those decisions.

The scoring weights are demonstration values, not BMW policy. The OpenAI API is not connected yet; the current records are sample data so the workflow can be reviewed before API access is configured.
